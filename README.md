# Weather CLI

Fetches live weather for a city using [wttr.in](https://wttr.in).

## How to run

1. Clone the repo and install dependencies:
```bash
pip install -r requirements.txt
```

2. Create a `.env` file in the project folder:

## CITY=YourCityName


3. Run the script:
```bash
python main.py
```

If no `CITY` is set in `.env`, it defaults to Phnom Penh.
